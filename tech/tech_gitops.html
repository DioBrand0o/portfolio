🔄 GitOps & ArgoCD

🎯 Vue d'ensemble GitOps

Objectif : Déploiement et gestion automatisés des applications Kubernetes via Git comme source de vérité unique.

Approche : ArgoCD déployé via Terraform avec ApplicationSets pour génération automatique d'applications multi-environnements.

Résultat : Infrastructure déclarative complète avec dual-repo pattern, automation Renovate et monitoring intégré.

🏗️ Architecture GitOps Enterprise

🚀 Déploiement ArgoCD via Terraform

Configuration ArgoCD - Terraform locals
locals { argocd_domain = "argocd.${var.ingress_domain}" # 🔑 FQDN dynamique argocd_bootstrap_repo_url = var.bootstrap_repo_url # 🔑 Repo GitOps argocd_namespace = "argocd" argocd_manifests = [ # 🔑 Certificate ECDSA personnalisé (pas auto-généré) { apiVersion = "cert-manager.io/v1" kind = "Certificate" metadata = { name = "argocd-server" namespace = local.argocd_namespace } spec = { subject = { organizations = [var.ingress_domain] # Subject personnalisé organizationalUnits = ["Kubernetes"] } commonName = "Argo CD Server" dnsNames = [local.argocd_domain] privateKey = { algorithm = "ECDSA" # 🔑 ECDSA plus sécurisé que RSA size = 256 # Courbe P-256 } duration = "4320h" # 🔑 6 mois (vs 3 mois défaut) secretName = "argocd-server-tls" issuerRef = { kind = "ClusterIssuer" name = "ingress" # CA interne (pas Let's Encrypt) } } }, # 🔑 Bootstrap Application - App of Apps pattern { apiVersion = "argoproj.io/v1alpha1" kind = "Application" metadata = { name = "bootstrap" # 🔑 Point d'entrée GitOps namespace = local.argocd_namespace } spec = { destination = { namespace = local.argocd_namespace server = "https://kubernetes.default.svc" } project = "default" source = { path = "bootstrap" # 🔑 Dossier ApplicationSets repoURL = local.argocd_bootstrap_repo_url targetRevision = "HEAD" } } } ] }
Helm Template - ArgoCD via Terraform
data "helm_template" "argocd" { namespace = local.argocd_namespace name = "argocd" repository = "https://argoproj.github.io/argo-helm" chart = "argo-cd" # 🔑 Renovate comment pour auto-update # renovate: datasource=helm depName=argo-cd registryUrl=https://argoproj.github.io/argo-helm version = "8.1.3" # 🔑 Version trackée par Renovate kube_version = var.kubernetes_version api_versions = [] values = [file("${path.module}/helm/argocd-values.yaml")] # 🔑 Values séparés }

🔄 Migration Azure DevOps → GitLab CI/CD Homelab

📋 Contexte du Projet

Objectif : Migrer un environnement de développement d'Azure DevOps vers une solution self-hosted GitLab CI/CD sur infrastructure Kubernetes Talos.

Infrastructure cible :

  • Hyperviseur Proxmox VE
  • Cluster Kubernetes Talos (3 control planes + 3 workers)
  • Stack GitOps avec ArgoCD et ApplicationSets
  • CNI Cilium avec cert-manager
Note : Il s'agit d'un environnement de homelab à des fins d'apprentissage et d'expérimentation, pas d'un environnement de production.

⚖️ Comparaison des Solutions

🔴 Azure DevOps

Secrets Management :
• Azure Key Vault
• Sealed-Secrets Kubernetes
• Gestion manuelle des rotations

CI/CD :
• Azure Pipelines
• Agents cloud ou self-hosted
• Facturation par minutes pipeline

Caractéristiques :
• Solution cloud native
• Intégration Microsoft ecosystem
• Maintenance gérée par Microsoft

🟢 GitLab CI + Vault

Secrets Management :
• HashiCorp Vault
• External Secrets Operator
• Rotation automatique configurable

CI/CD :
• GitLab Runner on Kubernetes
• Executor Kubernetes (pods éphémères)
• Infrastructure self-hosted

Caractéristiques :
• Contrôle total de l'infrastructure
• Solution agnostique cloud
• Maintenance self-service

🏗️ Architecture Technique Implémentée

🎯 GitOps avec ArgoCD
Déploiement GitOps via ApplicationSets avec pattern app-of-apps pour gestion centralisée.
🔐 HashiCorp Vault
Secret management avec UI web, policies RBAC et intégration Kubernetes native.
🚀 GitLab Runner
Déploiement dans Kubernetes avec executor Kubernetes pour isolation des jobs.
🔗 External Secrets Operator
Synchronisation automatique Vault vers Kubernetes Secrets avec gestion TTL.
🌐 Cilium CNI
CNI eBPF avec LoadBalancer L2, cert-manager pour TLS automatique.
🔧 ApplicationSet Pattern
Auto-discovery d'applications via fichiers de configuration JSON simplifiés.
📦 Kaniko
Construction d’images Docker sans Docker daemon, idéale pour CI/CD dans Kubernetes et runner éphémères. Sécurise la build d’images container en évitant les privilèges root.
🧹 Clean / Cleanup
Automatisation du nettoyage des artefacts, images temporaires et ressources obsolètes pour garantir un pipeline propre et éviter les fuites de ressources.
🔐 HashiCorp Vault (complément)
Gestion sécurisée des secrets avec authentification dynamique, renouvellement automatique des tokens, et intégration native Kubernetes via External Secrets Operator.
